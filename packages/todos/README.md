# @keydown-dev/pi-todos

Placeholder for a first-party todo list extension.

Planned capabilities:

- Tool for create/update/list/get/delete/clear actions.
- Session-backed state with optional project persistence later.
- Compact/expanded widget sharing the `pi-loops` visual grammar.
- Independent installation; no dependency on the `pi-loops` runtime.

See `../../plans/monorepo-extensions.md`.
