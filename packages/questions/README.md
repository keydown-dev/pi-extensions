# @keydown-dev/pi-questions

Placeholder for a first-party structured Q&A extension.

Planned capabilities:

- Tool for asking 1-4 structured questions with 2-4 options each.
- Single-select, multi-select, custom answer, chat/dismiss, and review flows.
- Optional preview panes for code, diagrams, and configuration comparisons.
- Non-obscuring UI aligned with the `pi-loops` widget.
- Durable typed custom answers when focus changes.

See `../../plans/monorepo-extensions.md`.
